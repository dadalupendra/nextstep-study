NextStep Study — Privacy Policy

Last updated: November 26, 2026

What we collect

The native app's offline mode stores the display name you choose, local notes, flashcards, tasks, study history and preferences on your device. Offline data is not transmitted to our server. No personal analytics, advertising SDK or third-party tracking has been intentionally added to this native app.

Optional cloud accounts

Cloud authentication is disabled until a separate Supabase project is configured and launched. If enabled in a future version, signing up requires an email address and password and optional two-factor authentication. Authentication records and encrypted token handling are provided by the configured authentication service. A study backup is uploaded only when you explicitly select Save study data to cloud.

Translation and external content

Opening the JLPT Library loads pages hosted on GitHub Pages. Selecting in-app translation on the web reader may send the selected lesson text and language pair to MyMemory, and opening external translation may send the page URL or selected text to Google Translate. Do not translate or upload private notes through these services.

Storage and retention

Offline data remains on your device until you delete it or remove the app. If optional cloud accounts become active, the cloud service keeps account and backup information until you delete the account, subject to legally required retention and provider security logs.

Your choices and deletion

In the native app, use Profile → Delete my local data to erase notes, tasks, flashcards and progress from this device. If you have a cloud account, choose Delete my cloud account to request removal of the account and its cloud backup. You may also stop using the app and uninstall it.

Age restrictions

Online account registration is blocked for users under 18 until a verified parental-consent process is deployed and applicable child-privacy obligations are reviewed. Offline educational content may still be available subject to local laws and supervision.

Security

The optional cloud design uses HTTPS, server-side authentication, a per-user database access policy and platform secure storage for session tokens. No software can guarantee absolute security. These protections require actual backend configuration and testing before public cloud accounts are enabled.

Questions

For questions about this policy, use the NextStep Study feedback page. Do not include passwords, recovery codes or other sensitive information in public feedback.
