Checking your browser…

🤖 Android

  1. Open this page in Chrome.
  2. Tap Install App above when available, or open Chrome ⋮ menu.
  3. Select Install app or Add to Home screen (wording varies).
  4. Tap Install. NextStep Study opens from your home screen.

🍎 iPhone / iPad

  1. Open this website in Safari.
  2. Tap the Share button (or Safari page menu, depending on your version).
  3. Choose Add to Home Screen.
  4. Choose Add. Open the icon on the home screen.

iOS does not offer the same automatic browser install prompt as Android Chrome.

💻 Windows PC

  1. Open this website in Microsoft Edge or Google Chrome.
  2. Click Install App when the prompt is available.
  3. Or in Edge, open ⋯ → Apps → Install this site as an app; in Chrome, use ⋮ → Cast, save and share → Install page as app (menu varies by version).
  4. Confirm. Launch NextStep Study from the Windows Start menu.

📚 Reading offline

Previously visited pages and loaded study materials may be available without internet after the site has been installed and cached. Before going offline, open the books and papers you need while online. Large books, first-time exam datasets, external media, and some features still require internet; your device can remove stored caches.
