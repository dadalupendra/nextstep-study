WHAT IS INCLUDED
- 700 N1 kanji entries (readings, meanings, examples, radicals/strokes)
- 1,000 N1 vocabulary entries (readings, English glosses, example sentences)
- 123 distinct N1 grammar patterns from OpenJLPT (meaning, usage, formation,
  examples), plus 500 practice-card/question opportunities
- 88 lessons: 35 Kanji + 13 Grammar + 40 Vocabulary
- Each lesson: 50 source-based original Japanese question/answer choices.
  Click a choice => instant right/wrong plus ALL FOUR options explained
  in Japanese / English / Nepali (Nepali translated meaning requires internet).
- Vocabulary filtering by JMdict POS classes: Noun, Pronoun, Verb,
  Adjectives, Adverb, Particle, Auxiliary, etc. Unclassified if source
  does not supply an interpretable class. Some words have multiple classes.
- Furigana ON/OFF for examples that include source furigana and
  word readings. Reading-answer drills intentionally do not expose hints.
- Daily Challenge: 5 Kanji + 5 Vocabulary flashcards each Tokyo day;
  browser localStorage saves today's progress.
- Each chapter printable with questions and all four option explanations:
  Save Chapter as PDF in browser print dialog.
- Full printable 1,000-page book: 700 Kanji pages + 123 Grammar pages
  + 177 Vocabulary pages. The browser generates the pages on demand.
- Translation buttons to Nepali and many other languages (internet required).
- Progress saved in your browser; no login, no API key.

PDF कसरी बनाउने?
 N1 खोल → Lesson छान → Save Chapter as PDF → Browser Print window
 → Destination "Save as PDF" → Save. 'Quiz & Papers' मा Full Book पनि छ।

IMPORTANT TRUTH / REFERENCE
 No official comprehensive JLPT N1 lists published after 2010. The OpenJLPT
 N1 dataset has 123 distinct N1 grammar patterns; 500 unique N1 grammar
 patterns are NOT claimed. This application creates 500 extra grammar
 practice cards/questions, not fabricated patterns.
 All data arrives from online OpenJLPT at the first visit, unless you first
 run Download_N1_Data.ps1 on Windows and upload N1/data/*.json. If you want
 completely self-hosted data, run the .ps1 script on your computer first.
 This ZIP does not contain a pre-rendered 1,000-page PDF; the browser's
 Print → Save as PDF generates the printable workbook from loaded data.
 Machine translation requires online service and can fail or be incorrect.
 Nepali and Japanese meanings are NOT manually pretranslated for all items.
 Offline POS/readings and explanation structure use source data.
 Study questions are original, not official exam papers.
