# NextStep Study — GitHub Pages

Static study website for JLPT N5, N4 and N3. N2/N1 are placeholders.

## Publish
Upload the contents of this folder (not the outer folder/ZIP itself) into the root of your `nextstep-study` GitHub repository on the `main` branch. In Settings → Pages, select Deploy from a branch → main → /(root).

The public site will be `https://dadalupendra.github.io/nextstep-study/` after a successful deployment.

The N3 reader includes its original assets (kanji SVGs, PDF files). N5 and N4 interactive readers were supplied as standalone HTML. No N5/N4 PDF was included in the uploaded archive. WordPress PHP plugins are not used.

Study progress is browser-local; no accounts or server synchronization.
